# TIBAPU College — Static Website

This is a static HTML, Bootstrap 5 and JavaScript website. It has no Django/Python backend and can be hosted using GitHub Pages.

## Pages
- `index.html` — Home
- `about.html` — About
- `courses.html` — Courses
- `contact.html` — Contact

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `tibapu-college`.
2. Upload all files and folders in this project to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. The public URL will be shown in Settings → Pages.

## Important
- Bootstrap is loaded from a CDN, so visitors need an internet connection.
- The contact page uses phone and WhatsApp links; it does not save form submissions.
- Confirm the official spelling, exact location/address, course names, fees, entry requirements, accreditation and admission dates with the college before publishing.
- This site uses a sample education-related hero photograph. Replace it with an approved photo of the college when available.
